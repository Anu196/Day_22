### Project Statement

**Customer Support Agent with Ticket Classifier** is a Multi-Agent AI system developed using **Python, AutoGen, and Google Gemini**. The system automates customer support by using two specialized AI agents. The **Ticket Classifier Agent** analyzes customer issues and classifies them into categories such as Billing, Technical, Account, General, or Feedback while assigning an appropriate priority level (Low, Medium, or High). The **Customer Support Agent** then uses the classified information to generate a professional, polite, and step-by-step response to help resolve the customer's issue. This project demonstrates AI agent collaboration, task delegation, and automated customer support.

---

## Working Statement

The system follows a multi-agent workflow:

**Customer Issue → Ticket Classifier Agent → Customer Support Agent → Final Customer Response**

* The user enters a customer support issue.
* The Ticket Classifier Agent identifies the ticket category and priority.
* The Customer Support Agent analyzes the classified ticket.
* The agent generates a professional response with troubleshooting steps and guidance.

## Features

* Multi-Agent AI System
* Built using Python, AutoGen, and Google Gemini
* Automatic ticket classification
* Priority detection (Low, Medium, High)
* Category detection (Billing, Technical, Account, General, Feedback)
* Professional customer support response generation
* Step-by-step troubleshooting

## Objective

The objective of this project is to automate the customer support process by using multiple AI agents that work together to classify customer issues, determine their priority, and generate accurate and professional responses, thereby improving efficiency and reducing response time.
